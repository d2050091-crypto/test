# CDA — Cyber & Digital Academy

Flask + SQLite (Python-ის ჩაშენებული `sqlite3`). ფრონტენდი ჩვეულებრივი HTML/CSS/JS-ია, ბილდი არ სჭირდება.

## გაშვება
    pip install -r requirements.txt
    ADMIN_EMAIL=შენი@ელფოსტა.com python3 server.py

გახსენი http://localhost:3000 და დარეგისტრირდი ზუსტად ამ ელფოსტით: გახდები ადმინი.
ან არსებულ ანგარიშს ადმინის როლი მიანიჭე: `python3 make_admin.py ელფოსტა პაროლი`.
პროდაქშენი: `gunicorn -w 1 --threads 8 -b 127.0.0.1:3000 server:app`

### გარემოს ცვლადები
| ცვლადი | რისთვის |
|---|---|
| `PORT` | პორტი (3000) |
| `DB_FILE` | ბაზის ფაილი (ნაგულისხმევად `cda.db` პროექტის საქაღალდეში) |
| `PAY_INFO` | გადახდის რეკვიზიტები, რომელიც განაცხადის შემდეგ ეჩვენება მოსწავლეს |
| `CONTACT` | კონტაქტი ფუთერში |
| `MENTOR_NAME` | შენი სახელი მენტორის ბლოკში |
| `TRUST_PROXY=1` | თუ საიტი nginx/Cloudflare-ის უკან დგას |
| `SECURE_COOKIE=1` | cookie-ს Secure დროშა (HTTPS-ზე ავტომატურადაც ირთვება) |

## სტრუქტურა
- `server.py`: API, უსაფრთხოება, სტატიკური ფაილები
- `db.py`: ბაზა, მიგრაცია, კურსის ჩატვირთვა
- `content.json`: **კურსის მასალა** (გადატვირთვისას ბაზა განახლდება, ვიდეო/PDF ბმულები არ იშლება)
- `plans.py`: **გეგმები და ფასები**
- `public/`: ფრონტენდი (`index.html`, `css/style.css`, `js/app.js`, `js/theme.js`, `img/`)
- `test_api.py`: ტესტები: `python3 test_api.py`

## უსაფრთხოება
- პაროლები: scrypt + მარილი; მარტივი პაროლები (`password123` და მისთანანი) იბლოკება
- სესიის ტოკენები ბაზაში **ჰეშის სახით** ინახება; ერთ მომხმარებელს მაქსიმუმ 10 სესია
- CSRF: cookie `SameSite=Lax` + Origin/Referer შემოწმება + API მხოლოდ JSON-ს იღებს
- CSP ინლაინ სკრიპტებისა და სტილების გარეშე, `object-src 'none'`, HSTS (HTTPS-ზე), COOP/CORP, `nosniff`, `X-Frame-Options`
- ლოგინის, რეგისტრაციის, პაროლის შეცვლისა და ანგარიშის წაშლის შეზღუდვა (rate limit)
- `.`-ით დაწყებული ფაილები და ყველაფერი `public/`-ს გარეთ მიუწვდომელია
- ანგარიშის გვერდზე: „გასვლა ყველა მოწყობილობიდან“ და ანგარიშის თვითწაშლა

**ყურადღება:** პირველი გაშვებისას ძველი სესიები ერთხელ წაიშლება (ტოკენების ჰეშირების გამო): ყველა ხელახლა შევა.

## გამოქვეყნებამდე
- **HTTPS აუცილებელია** (Caddy ან nginx + Let's Encrypt).
- გააკეთე `cda.db`-ის რეგულარული ასლი (ფაილი + `-wal`/`-shm`, ან `sqlite3 cda.db ".backup b.db"`).
- წესები და კონფიდენციალურობა (`#/terms`, `#/privacy`) ნიმუშია: გადაამოწმებინე იურისტს.
- ელფოსტით პაროლის აღდგენა არ არის: ადმინში „პაროლი“ ღილაკი დროებით პაროლს ქმნის.
- ტესტური `cda.db` (admin@gmail.com) ნუ გამოაქვეყნებ: დაიწყე ახალი ბაზით.
